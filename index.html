⚠️ Tentang data

Dashboard ini mengambil data cuaca melalui fungsi serverless /api/weather (atau scripts/dev-server.js pada host Node.js). Sumber utama adalah OpenWeather; bila OpenWeather tidak dapat dijangkau atau API key belum diatur, server otomatis beralih ke Open-Meteo yang live tanpa API key, dan payload selalu menyebutkan sumbernya. API key hanya hidup sebagai environment variable di server dan tidak pernah masuk ke JavaScript browser. Cuaca saat ini, prakiraan, kualitas udara, dan minute forecast diperbarui otomatis sekitar setiap 10 menit. Hanya bila kedua penyedia gagal, antarmuka menampilkan fallback lokal yang ditandai jelas, bukan angka palsu. Radar tetap simulasi; kalender bulanan memakai data contoh; skor kesehatan bukan diagnosis atau nasihat medis.

Dokumen resmi sumber data: One Call API 4.0 · Current Weather · 5-day Forecast · Air Pollution · Weather Maps · Product features · Open-Meteo (cadangan live).
