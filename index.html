⚠️ Tentang data

Dashboard ini mengambil data cuaca Klumprit dari OpenWeather melalui proxy di server.js. API key hanya hidup sebagai environment variable di server dan tidak pernah masuk ke JavaScript browser. Saat key tersedia, cuaca saat ini, prakiraan, kualitas udara, dan minute forecast diperbarui otomatis sekitar setiap 10 menit — mengikuti periode update model OpenWeather, bukan polling setiap detik. Bila key belum dikonfigurasi atau langganan belum aktif, antarmuka menampilkan fallback lokal yang ditandai jelas, bukan angka palsu. Radar tetap simulasi; kalender bulanan memakai data contoh; skor kesehatan bukan diagnosis atau nasihat medis.

Dokumen resmi sumber data: One Call API 4.0 · Current Weather · 5-day Forecast · Air Pollution · Weather Maps · Product features.
